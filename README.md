# 🧠 ThinkCode

> **Learn to Think Like a Programmer Without Writing Code.**

ThinkCode is an interactive web-based educational platform designed for middle school students (Grades 7–9) to develop computational thinking skills through engaging visual logic games. Instead of focusing on programming syntax, students learn essential problem-solving concepts such as sequencing, pattern recognition, debugging, loops, and conditional logic in a fun, intuitive, and gamified environment.

## ✨ Features

- 🎮 7 Interactive Logic Games
- 📚 Built-in Learning Materials
- ⭐ 3-Star Performance Evaluation
- 🔊 Web Audio API Sound Effects
- 📱 Fully Responsive Design
- 🎨 Modern and Student-Friendly Interface
- 🏆 Progressive Level System
- 📊 Learning Progress Tracking

## 🎯 Learning Objectives

- Develop Computational Thinking
- Improve Logical Reasoning
- Strengthen Problem-Solving Skills
- Understand Fundamental Programming Concepts
- Build Algorithmic Thinking Without Coding Syntax

## 🎮 Games

### 🤖 Logic Maze
Guide a robot through a maze by arranging movement instructions in the correct sequence.

### 🧩 Block Coding
Build visual instruction blocks to solve puzzles, collect gems, and unlock doors.

### 🔍 Pattern Puzzle
Identify patterns and predict the missing element using logical reasoning.

### 🐞 Debug Challenge
Find and fix logical errors in visual programs to complete each mission.

### 🔁 Loop Adventure
Learn repetition by creating efficient loop structures to complete long paths.

### 🌦️ If-Else Adventure
Make decisions based on changing conditions using visual conditional logic.

### 📝 Logic Builder
Arrange real-world activities into the correct chronological algorithm.
